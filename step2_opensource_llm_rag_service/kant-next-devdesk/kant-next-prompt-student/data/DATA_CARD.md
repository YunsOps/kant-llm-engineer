# KANT NEXT DevDesk 예제 자료

과제전형에 제공된 테스트용 정책, 티켓과 문의입니다. 실제 고객 정보나 기밀은 포함하지 않습니다. `.invalid` 주소는 출처를 식별하기 위한 값이며 접속 대상이 아닙니다.

| 파일 | 내용과 사용 범위 |
|---|---|
| `documents.json` | 개발지원 정책 6개. `doc_id`, `title`, `body`, `source_url`, `collected_at`, `category` 여섯 필드로 구성합니다. |
| `tickets.json` | 읽기 전용 테스트 티켓 2개. IT-1042는 조사 중이며 확정 복구 시각이 없습니다. IT-1043은 해결 상태입니다. |
| `evaluation_cases.json` | 정상 정책, 범위 밖, 미확정 정보, 비밀정보, 티켓, 이미지 질문 10개와 공개 기대 분류. 본문의 사실성까지 자동 판정하는 정답 목록은 아닙니다. |
| `error_screenshot.png` | 테스트 터미널 화면. `401 Unauthorized`와 테스트 저장소 `packages.kant-next.invalid`를 표시합니다. 실제 장애 캡처나 인증정보가 아닙니다. |
| `prices.json` | 2026-09-18 공식 모델 문서에서 확인한 standard 단가. USD/백만 토큰이며 입력 272,000토큰 이하에만 적용합니다. |

과제 실행도 uv를 사용합니다. [실행 안내](../README.md)에 따라 제공된 `pyproject.toml`과 `uv.lock`으로 환경을 준비하세요. 제공된 정책 자료는 답변의 근거로 사용합니다.

사례는 `case_name`의 이름으로 확인합니다. `case_id`는 재현과 저장에 쓰는 내부 식별자입니다. 정책 프롬프트는 Python 버전 문의와 출장비 한도 문의를 두 조건으로 비교합니다. 최종 비교 명령은 전체 사례와 지정된 반복을 자동 실행해 결과 26개를 저장합니다. 선택 심화는 Python 버전 문의, 출장비 한도 문의, 비밀번호 요구를 newcomer/operator 두 모드로 실행합니다.

`expected_source_ids`는 질문의 핵심 판단에 필요한 최소 출처입니다. 답변 내용에 맞는 다른 제공 문서를 함께 인용할 수 있습니다. 예를 들어 비밀번호 요구의 비밀정보 거절은 `policy-secret`이 필요하며, 접근 권한 문의를 안내하면 `policy-access`를 보완 출처로 사용할 수 있습니다. 출처 개수보다 실제 본문과 근거의 일치를 검토합니다.

공개 fixture는 API 응답 형식과 제어 흐름을 검사하기 위한 테스트용 데이터입니다. `fixture-not-a-model`, `fixture-response` 등의 식별자를 실제 모델, 비용, 캐시 적중을 확인한 결과로 해석하지 않습니다. 모든 모델 응답 본문은 근거 문서와 사람이 대조해야 합니다.

가격 출처: [gpt-5.6-luna 공식 모델 문서](https://developers.openai.com/api/docs/models/gpt-5.6-luna). 가격은 과제 실행 시 다시 확인할 수 있도록 출처, 확인일을 기록합니다. 단가 변경 시 동일 비교 묶음에 다른 가격 버전을 섞지 않습니다.
